# NEXUS-7 — Neon District Map

Интерактивная демка cyberpunk-карты вымышленного квартала:

- здания на продажу с условиями
- слои: LRT, мега-мечеть, зелёные зоны
- таймлайн 2024→2032: развитие района, цены, фазы стройки, планы «что дальше»
- mobile bottom-sheet для карточки объекта

```bash
npm install
npm run dev
```
